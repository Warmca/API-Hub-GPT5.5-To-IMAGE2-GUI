─────────────────────────────────────────────────────────────────────────────
推荐用法（按你大多数情况下走 GUI）

1) 主提示词、主体、人物细节、场景 —— 直接在 GUI 各字段里手写
2) 拍摄风格字段 —— 从 完整风格/ 挑一个粘贴过来，或自己写
3) 避免内容字段 —— 粘贴 _反AI生成感总纲_cn.txt 末尾的 avoid 段，
   再追加 辅助片段/负面_AI破绽扩展.txt 和 负面_手部畸形防御.txt
4) "提示词文件"加载位 —— 挂 2-4 个辅助片段（多了会冲淡主题）
   常用组合：
     · 写人脸：肤质_毛孔与血色 + 肤质_脸型微不对称 + 发丝_自然飞散
     · 写街拍：构图_扰动与离心 + 镜头_轻微瑕疵 + 场景_氛围道具
     · 写胶片感：胶片_颗粒控制 + 光位_色温混合 + 镜头_轻微瑕疵
     · 写室内自然光：光位_轮廓发光 + 光位_反光补面 + 场景_背景虚化层次


─────────────────────────────────────────────────────────────────────────────
CLI 用法（一次叠多个 --prompt-file）

  python API_GPT5_5_to_IMAGE2.py "an early-20s woman, candid window seat" \
      --prompt-file prompt_examples/_反AI生成感总纲_cn.txt \
      --prompt-file prompt_examples/完整风格/胶片35mm人像_cn.txt \
      --prompt-file prompt_examples/辅助片段/肤质_毛孔与血色.txt \
      --prompt-file prompt_examples/辅助片段/构图_扰动与离心.txt \
      -q high -s 2160x3840 -n 2


─────────────────────────────────────────────────────────────────────────────
组合原则
- 辅助片段：选 2-4 个互补不重复的，别全部叠（GPT-5.5 会无所适从）
- 同一类只选一个：例如 光位_轮廓发光 和 光位_反光补面 都偏布光，最多一个
- 负面_xxx 文件的内容应进入 avoid_prompt 字段而非正向，否则反作用
